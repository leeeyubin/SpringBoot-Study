# 버전 관리 시스템

## 버전 관리 시스템의 개요

### 버전 관리 시스템의 개념
> `버전 관리 시스템`이란, 파일의 변화를 시간에 따라 버전별로 기록했다가 나중에 다시 꺼내 사용할 수 있도록 만든 시스템이다.


### 버전 관리 시스템의 공유

- 중앙 집중식 버전 관리 시스템 (CVCS, Centralized VCS)
  - 중앙에 서버를 두고 저장소로 사용하면서 네트워크로 연결된 모든 컴퓨터의 파일 변경 내역을 저장하고 관리하는 방식
  - `단점` ⬇️
    - 모든 컴퓨터가 네트워크에 연결되어 있어야 함
- 분산 버전 관리 시스템(DVCS, Distributed VCS)
  - 모든 사용자의 컴퓨터가 저장소로서 버전 관리를 담당하는 방식
  - `장점` ⬇️
    - 파일을 한 번 저장소에서 받아온 다음 서버와 별개로 작업 가능
    - 로컬에서 작업하기 때문에 속도 빠름
    - 서버에 문제가 생겨도 개발자가 작업하는 데 지장 없음
  - 개인의 컴퓨터와 서버 컴퓨터는 `병합`(merge) 및 `가져오기`(pull) 작업을 하여 양쪽 시스템 간의 동기화 수행함

## 분산 버전 관리 시스템: 깃

### 깃의 작업 영역

- `작업 공간`
  - 현재 작업하고 있는 공간
- `스테이징 영역`
  - 작업 공간에서 발생한 상태 변화 중 실제 내부 저장소에 변경 이력으로 남길 작업을 선정하는 공간
  - git add 명령어를 통해 변경 이력 남길 파일 올릴 수 있음
- `내부 저장소`
  - 스테이징 영역에서 git commit 명령어를 통해 이동하는 영역으로, [.git] 폴더를 의미

## 웹 기반 버전 관리 저장소: 깃허브
<img src = "https://github.com/user-attachments/assets/55f85f5b-4cb1-440d-8fea-d74b4fde3983" width="100">


> `깃허브`는 대표적인 외부 저장소로, 깃으로 관리하는 프로젝트를 업로드할 수 있도록 웹 기반 저장소를 생성하고 관리하는 서비스이다.

### 깃허브 동작 방식

1. 프로젝트 매니저가 폴더 생성한 후 소스 코드 저장 -> 해당 폴더에 [.git] 저장소 만들고 최초의 스냅숏 저장
2. 자신의 컴퓨터에 있는 스냅숏을 외부 저장소인 깃허브에 업로드
3. 팀원들은 깃허버를 이용해 프로젝트 폴더에 저장된 소스 코드 파일과 [.git] 저장소에서 관리하는 모든 스냅숏을 내려받아 작업
