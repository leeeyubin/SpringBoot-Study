# 클라우드 컴퓨팅

## 클라우드 컴퓨팅의 개요

### 클라우드 컴퓨팅의 개념

> `클라우드 컴퓨팅`이란, 언제 어디서든 인터넷을 통해 접속할 수 있는 컴퓨텅 환경으로, 간단히 `클라우드`라고도 한다.

- 온프레미스 시스템
  - 클라우드가 도입되기 전에 개인 또는 기업 자체적으로 서버를 구축하고 운영하던 시스템이다.
  - 그래서 사용자가 직접적으로 보안과 데이터 소유권을 통제할 수 있다.
- 클라우드 시스템
  - IT 자원을 클라우드 서비스 제공 업체에 의뢰해 관리하는 방식이다.
  - 인터넷에 연결된 어느 장치에서나 접속이 가능하며, 업체가 제공하는 다양한 기능과 서비스를 이용할 수 있다.

### 클라우드 서비스의 종류

📍 제공방식, 환경에 따라
  - `공용 클라우드` : 다수의 사용자가 공유하는 클라우드 환경으로, 클라우드 서비스 제공 업체가 소유하고 관리한다.
  - `사설 클라우드` : 단일 조직이나 기업이 사용하는 클라우드 환경으로, 조직이나 기업 자체가 소유하고 운영한다.
  - `하이브리드 클라우드` : 공용 클라우드와 사설 클라우드를 조합한 형태이다.

📍 범위에 따라
- `IaaS` : 클라우드 서비스 제공 업체가 가상 인프라를 제공하는 모델로, 플랫폼과 소프트웨어를 지원하고 실행하기 위한 기반을 제공한다.
- `PaaS` : 웹 애플리케이션을 구축하고 실행할 수 있는 인프라와 플랫폼을 제공한다.
- `SaaS` : 클라우드 서비스 제공 업체가 아예 웹 애플리케이션을 제공하는 모델이다.

## 클라우드 서비스: AWS

### Amazon EC2 : 가상 서버 서비스

- `Amazon EC2` : 원격으로 제어할 수 있는 서버 컴퓨터를 빌리는 서비스이다.
  - 이를 사용하면 개발자는 필요에 따라 EC2 인스턴스를 시작, 중지, 다시 시작, 종료 및 스케일링을 할 수 있다.
- ` Amazon S3` : 파일을 저장하는 데 사용되는 스토리지 서비스이다.
- `Amazon RDS` : 관계형 데이터베이스를 구축하고 관리할 수 있도록 도와주는 클라우드 서비스이다.
  - 이를 사용하면 데이터베이스를 만드는 데 필요한 부품을 직접 설계하고 개발할 필요 없이 이미 준비된 데이터베이스 관리 시스템을 조립해 사용할 수 있다.
- `Amazon IAM` : AWS 자원에 접근하고 사용할 수 있는 사용자의 권한을 제어한다.
