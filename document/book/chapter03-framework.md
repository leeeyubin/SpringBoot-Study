# 백엔드 개발 언어와 프레임 워크

## 프로그래밍 패러다임

> 프로그래밍 패러다임: 프로그래밍에서 일반적인 문제를 해결하는 데 사용하는 기본적인 철학이나 접근방식

#### 📍 명령형 프로그래밍

- 명령형 프로그래밍은 '어떻게 문제를 해결할 것인가'에 초점을 두고 연속된 명령어로 표현하는 프로그래밍 방식이다.

#### 📍 절차지향 프로그래밍

- 절차지향 프로그래밍은 명령형 프로그래밍에 속하는 방법론 중 하나로, 각 명령에는 순서가 있고 반드시 한 방향으로 수행돼야 한다는 원칙에 따라 동작한다.
  - `장점`: 컴퓨터가 내부적으로 명령을 처리하는 구조와 유사해 실행 속도가 빠르다.
  - `단점` : 유지보수와 디버깅이 어렵다.

#### 📍 객체지향 프로그래밍

- 객체지향 프로그래밍은 실세계를 모델링해 프로그램을 개발하는 방법이다.
  - 이때, 실세계를 모델링한다는 것은 특정 사물의 본질을 '속성'과 '기능'으로 정의한다는 거다.
- 주요 특징으로는 추상화, 캡슐화 상속이 있다.
  - `추상화` : 공통 속성과 기능을 추출해 이름을 붙이는 과정 (= 클래스 정의) 
  - `캡슐화` : 속성과 그 속성을 조작하는 기능(함수)을 하나의 '캡슐'로 묶는 것
  - `상속`: 기존 상위 클래스의 속성과 기능을 가져다 하위 클래스에 재사용하는 것

#### 📍 함수형 프로그래밍

- `불변성` : 데이터는 일단 생성되면  변하지 않는다.
  - 불변성은 데이터가 엉뚱한 값으로 변하지 않음을 보장하는데, 이를 '참조 투명성'이 있다고 표현한다.
- `선언형` : 함수형 프로그래밍은 '무엇을 할 것인지'에 초점을 둔다.

## 백엔드 개발 언어

#### 📍 자바스크립트
<img width="80" src="https://github.com/user-attachments/assets/10436eb3-090e-4dd6-8ea4-51c82078bba1" />

> 자바스크립트는 웹 페이지의 정적인 HTML 콘텐츠를 동적으로 변경하거나 이벤트와 같은 상호작용을 구현하기 위한 스크립트 언어이다.

- 자바스크립트는 웹 브라우저에만 동작하는 인터프리터 방식 언어이다.

#### 📍 타입스크립트
<img width="80" src="https://github.com/user-attachments/assets/8978f111-b7f7-4ca2-8223-3cedc4ecc98c" />

> 타입스크립트는 자바스크립트의 단점을 보완하기 위해 만든 컴파일 언어이다.

 - 즉, 자바스크립트의 모든 기능을 유지하면서 정적 타입과 관련된 문법을 추가한 것이다.
- 그래서 자바스크립트는 자바스크립트의 상위 집합으로 볼 수 있다.

#### 📍 자바

<img width="100" src="https://github.com/user-attachments/assets/8e82f854-e830-487f-8abf-fa854dc702e6">

> 자바는 썬마이크로시스템즈가 개발한 객체지향 프로그래밍 언어이다.

- 자바는 자바 가상머신인 JVM을 통해 실행된다.
- 자바는 숫자(int, float, long..)와 논리 값(true, false)을 제외한 거의 모든 데이터를 객체로 구성한다.
- 자바는 모든 메모리에 접근을 자바 시스템이 관리하고 제한한다.

## 백엔드 프레임워크

- `라이브러리`는 개발하는 데 필요한 기능을 미리 구현해놓은 코드의 모음집이다.
- `프레임워크`는 복잡한 문제를 해결하거나 서술하는 데 사용되는 기본구조로, 그 이름에서 유추할 수 있듯이 뼈대 혹은 골조를 의미한다.
  - 즉 일정한 형태와 기능을 제공하는 툴이다.

#### 📍 Express.js: 자바스크립트 기반

- Express.js는 Node.js가 제공하는 API를 바탕으로 백엔드 개발을 할 수 있도록 만들어진 프레임워크이다.
  - `장점` : 프레임워크 자체가 경량화돼 간단하고 빠르게 웹 서버를 만들 수 있다.
  - `단점` : 고급 기능이나 대규모 프로젝트를 개발하기에 부족하다, Node.js 기반의 서버를 구축하기 때문에 멀티스레드를 지원하지 않는다.

#### 📍 NestJS: 타입스크립트 기반

- NestJS는 타입스크립트를 우선적으로 지원하고 자바스크립트로도 사용 가능한 프레임워크로, Express.js의 기능을 이어받아 보완 및 확장된 기능을 제공한다.

#### 📍 스프링: 자바 기반

- 스프링은 자바 기반의 백엔드 프레임워크이다.
- 스프링을 비롯해 대부분의 프레임워크가 추구하는 목적 중 하나는 개발자가 비즈니스 로직에 집중할 수 있도록 하는 것이다.

#### 📍 스프링 부트: 자바 기반

- 스프링 부트는 개발자가 스프링을 사용할 때 실행 환경이나 의존성 관리 설정에 들이는 시간과 에너지를 아껴 비즈니스 로직에 좀 더 집중할 수 있게 해 준다.
- 스프링 부트는 내부에 웹 애플리케이션 서버(WAS)인 톰캣을 가지고 있다.
